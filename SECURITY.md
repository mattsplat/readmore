# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 2.x     | ✅        |
| 1.x     | ❌        |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's
[security advisory form](https://github.com/mattsplat/readmore/security/advisories/new),
or by email to matthewjohncoleman@gmail.com. You'll get a response within a
reasonable time frame, and credit in the release notes if you'd like it.
